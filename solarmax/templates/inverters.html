First version

SigenStor EC 20.0 TP AU

The initial build reads live telemetry from the SigenStor over Modbus TCP using a pluggable adapter module. When the inverter is unreachable, all live values show "—" until it responds again — no simulated data is ever shown.

Future inverter types can be added by dropping in a new module under solarmax/inverters/ and adding it to the registry.
